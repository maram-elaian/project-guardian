# Project Guardian

Intelligent architecture protection and project organization for VS Code.

## Status

🚧 Under active development.

## Vision

Project Guardian helps developers understand, maintain, and improve the architecture of large codebases.

## Planned Features

- Project structure analysis
- Dependency analysis
- Architecture violation detection
- File placement recommendations
- Safe structural refactoring
- Architecture drift detection
- AI-powered explanations
